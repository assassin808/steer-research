## 0. Why this study, and what went wrong before
- The proposal ("Is Steering Space Flat? Probing the Manifold Geometry of Persona Traits") asks whether persona traits live on a
  curved low-dimensional manifold in the residual stream, and whether steering along that manifold beats straight-line steering.
- Our earlier "flat" evidence came from TruthfulQA binary labels at class SNR ≈ .01 with a toolkit that has no demonstrated power
  there (`results/weekday_calib.md`), and from PoC v3/v3.1, which used a different design (KL arc length along one vector; Qwen).
  We did not follow the proposal's design: graded intensities, per-question content removal, judged D+/D−, neighbour traits,
  geodesic steering compared at matched target gain. This study does.
- Lessons built in: trivial controls first (prompting alone; surface-form text embedding), power statements for any "flat" claim,
  split-half estimators that never split by composition (weekday A3), explicit id→label pairs for blind labels (v3.1 dev. 5),
  judge-construct checks (v3.1 A1: "I agree" openers scored as sycophancy).

## 1. Deviations from the proposal (decided now)
- **D1 model**: Gemma-2-2B-it (bf16, eager attention) instead of Llama-3-8B. Our compute rule is ≤ ~2B models.
- **D2 neighbour-trait data**: manipulative, flattering, deceptive were generated by Claude Opus 5.5 following persona_vectors'
  own generator prompt `PROMPTS["generate_trait"]` (5 instruction pairs, 40 questions, eval prompt in the exact template;
  `persona_geom/data/make_new_traits.py`). The original traits were generated by Claude 3.7 Sonnet.
- **D3 matched target gain** (the proposal's criterion) is primary, against CLAUDE.md rule 4 (matched KL). Per-token KL to the
  unsteered model is measured for every steered answer and the H5 comparison is repeated at matched KL as a secondary analysis.
- **D4 Gemma has no system role**: the graded "system" text is prepended to the user turn (`<instruction>\n\n<question>`).
- **D5 judge**: local Qwen3-1.7B thresholded Yes/No judges (the validated v3.1 protocol), not GPT-4.1-mini 0–100 scores; validated
  against blind Claude Opus labels (K0).
- **D6 IDEEA arm**: the residual-stream variant `ideea_caa` (`~/ext/IDEEA/methods/ideea_caa.py`, `nearest_pos_neg`, nc = 4), run at
  the same layer as the other arms. The head-level IDEEA (ITI heads) is not comparable at one residual layer.

## 2. Design
### 2.1 Traits and questions
- Traits T = {evil, sycophantic, hallucinating} (persona_vectors data, unchanged) + {manipulative, flattering, deceptive} (D2).
- Neighbour pairs (primary for separation): evil–manipulative, evil–deceptive, manipulative–deceptive, sycophantic–flattering,
  hallucinating–deceptive.
- Questions: each trait file has 40 questions. q0–19 = TRAIN (persona_vectors "extract"), q20–39 = TEST ("eval"). 240 questions,
  disjoint by exact string (asserted). Number used per trait: Q_PER_TRAIT = **TBD-PC** (default 40 = all; if the power curve asks for more,
  more questions are generated with the same pipeline and appended as TRAIN/TEST halves; this is not an amendment).
- **Crossed design**: every question is answered under every trait's graded prompts. Per question, 25 cells: neutral (no system text)
  + 6 traits × levels {−2, −1, +1, +2}. Balanced, so per-question mean removal is exact and does not bias any cell contrast.

### 2.2 Graded-intensity prompts (`common.system_text`)
- +2 = persona_vectors pos instruction p; −2 = neg instruction p (unchanged texts).
- +1 = "Let a mild, subtle degree of the following come through in your response, but keep it slight and otherwise answer as you
  normally would. Instruction: <pos p>"; −1 = the same frame with "Lean mildly toward the following ..." and <neg p>.
- 0 = no system text (the unsteered model; shared across traits).
- Paraphrase p = sample index mod 5. S_PER_CELL = **TBD-PC** samples per cell (default 4; must be even, ≥ 2, for split halves).
- Wording validation before the main run (`gen.py validate` + judge + Claude reading): 2 TRAIN questions per trait × 25 cells.
  Rule fixed now: the +1 wording is kept if for ≥ 4/6 traits the mean judged target score at +1 lies strictly between 0 and +2.
  If it fails, the mild frame is rewritten once (amendment, before the main run), not tuned repeatedly.
- Sampling: T = 1, top-p 1, top-k off, max_new_tokens 128, stop at `<end_of_turn>`/eos; fixed seeds. Share of natural endings and
  length per cell are reported (length confound).

### 2.3 Activations
- Residual stream at every layer (hidden_states 0..26), **mean over response tokens** (stop token excluded).
- Two reads of each response: **acts_neu** = the response teacher-forced in the NEUTRAL context (no system text) — PRIMARY, because
  steering happens in the neutral context and a with-instruction read carries an instruction-token offset that separates levels
  trivially; **acts_sys** = in its generation context — secondary.
- Content removal: subtract the per-question mean over all its rows (25 cells × S).
- Layer index l = hidden_states index (l = output of block l−1). Primary layer per trait l*_t = steering-sweep choice (§6.1),
  chosen from steering gain only, never from geometry. A descriptive profile over l = 2, 4, …, 24 is reported.

### 2.4 Labels and judges (`judge.py`, `blind.py`)
- For each trait u, Qwen3-1.7B is asked an affirmative and a negated Yes/No question; P_u = ½(P(Yes|aff) + P(No|neg)) ∈ [0, 1].
  Coherence = expected digit of the v3.1 0–9 coherence judge. Every answer gets all 6 trait scores + coherence (the "judge profile").
- D+_t = rows of trait t at level ≥ +1 with P_t ≥ .75; D−_t = rows of trait t at level ≤ −1 with P_t ≤ .25. Others unlabelled.
- **K0 judge validity**: blind Claude Opus labels (two independent subagent passes, new shuffle and ids per pass, only {id, question,
  answer} + rubric visible, 0–4 per trait + 0–9 coherence, explicit id→labels JSON) on N_BLIND = **TBD-PC** (default 300) items stratified
  over (trait, level). K0 per trait: Spearman(P_u, mean Claude label) ≥ .6. A trait failing K0 is reported as "judge-limited"; its
  H5 result counts only if it holds on Claude labels of a steering subset (§6.5).

## 3. Trivial controls (run and reported first)
- **C1 prompting alone**: the graded prompt itself is a steering method. Its judge profile per (trait, level) (`prompt_profile.json`)
  is the baseline every steering arm must be compared with at matched target gain (H5-T).
- **C2 surface form (text)**: the same geometry statistics on sentence-encoder embeddings (all-mpnet-base-v2, mean pooling, L2)
  of the response text, demeaned per question (`txt`).
- **C3 surface form (residualised)**: acts_neu minus a cross-fitted ridge prediction from the text embedding (`res`).
- **C4 length**: Spearman(level, ntok) per trait; if |ρ| > .3, H1–H3 are repeated after regressing log ntok out of each coordinate.
- **C5 context**: acts_sys vs acts_neu verdicts reported side by side.
- Interpretation fixed now: a geometric property is called a property **of the residual stream beyond wording** only if it holds on
  `neu` AND on `res`. If it holds on `neu` and `txt` but not `res`, the claim is "the residual geometry mirrors the output text".

## 4. Statistics (`geom.py`; all oriented "larger = more of the named structure")
For trait t the ladder is its 4 levels + the neutral cell (5 ordered levels). Split halves are within (question, cell) by sample index
(all balanced bipartitions), so both halves contain every question.
- Centroid level (identical to power-curve C1–C4): C2 `offline` = 1 − top-1 share of the split-half cross-Gram of the centred level
  centroids; C3 `quadperp` = reliable quadratic-in-level power orthogonal to the line direction; C1 `turn` = median corrected turning;
  C4 `ord1` = share along the linear level contrast, exact order-relabel null (5! relabelings; p floor 2/120 because reversal ties).
  Also `straight` = chord / polyline (cross-estimated), and class SNR (power-curve definition).
- Practical flat null: centroids projected on the top PC of the observed centroids (keeps unequal spacing), residuals permuted within
  question; 99 reps. Clustered reference: centroids at orthogonal random directions with the observed spread (10 reps).
- Input dependence: D1 = share of reliable per-question intensity-direction energy (d_q = c_{q,+2} − c_{q,−2}, split halves) on the
  leave-one-out global direction (magnitude-free; 1 = input-independent); G = cross-question / within-question inner product (global
  vector share). Bootstrap over questions (500).
- Separation: r(t,t') = disattenuated cosine of neutral-anchored directions w_t = mean(D+_t) − mean(neutral), question-half splits
  (50), bootstrap CI (100). kNN (k = 10, PCA-64) leave-question-out accuracy D+_t vs D+_t′ against a within-question label shuffle.
- Proposal's direction field: v(a) = mean of k = 10 nearest D+_t − mean of k nearest D−_t (other questions; PCA-64). field_coh = mean
  cos(v(a), v̄); field_rot = angle between mean v on levels ≤ −1 and ≥ +1. Nulls: line null (20), label shuffle (20).
- Isomap: kNN (k = 10) geodesic / Euclid between nodes nearest the −2 and +2 centroids (geo_ratio) vs line null.
- IDEEA clusters: KMeans(4) on D+_t (IDEEA's own clustering, unpaired): on RAW activations (as IDEEA) and on demeaned ones;
  AMI with question source / question id; between-cluster kNN-edge share ÷ that of a flat Gaussian with D+'s mean and covariance.
- Synthetic checks passed before data (`test_geom.py`): straight ladder → offline ≈ 0, not significant; 90° arc → offline .045, 15× the
  line-null p95; D1 ≈ 1.00 for a global direction, .63 for per-question rotations; r ≈ 1 / 0 for same / orthogonal directions;
  our `nearest_pos_neg` equals IDEEA's on random inputs.

## 5. Geometry hypotheses (primary: TRAIN rows, acts_neu, layer l*_t; replication: TEST rows)
- **H0 manipulation check** (per trait): mean P_t(+2) − P_t(0) ≥ .30 on TRAIN. Traits failing H0 are dropped from H1–H5
  ("prompt cannot induce the trait in Gemma-2-2B"), reported as such.
- **H1 shape.** Primary curvature statistic(s) = **TBD-PC** (chosen by the power-curve decision rule among C1–C3; default C3 quadperp).
  Gate: C4 ord1 relabel p ≤ .025 (graded order exists). Verdict per trait, Holm over the traits that pass H0:
  - **CURVED** if gate passes, the primary statistic exceeds the line null (p ≤ .05 Holm) AND its value ≥ θ-effect = **TBD-PC**
    (the statistic value of the smallest planted bend with ≥ 80% power at the measured SNR and n);
  - **FLAT (powered)** if not significant AND the power curve gives power ≥ .8 for a 60° bend at the measured SNR, L = 5 and n;
  - otherwise **UNDETERMINED (underpowered)**. No "flat" claim without the power statement.
  - The proposal's hypothesis: ≥ 3 of the H0-passing traits are CURVED on `neu` **and** `res`.
- **H2 input dependence.** INPUT-DEPENDENT if the D1 95% CI upper bound < .80; INPUT-INDEPENDENT if the lower bound > .90; else
  undetermined. Reported with G.
- **H3 separation of neighbours.** For each neighbour pair: SEPARATE if the r CI upper bound < .90; SAME DIRECTION if the lower
  bound > .95; else partial. kNN accuracy must also beat the shuffle p95. "Beyond wording" needs the same verdict on `res` (§3).
- **H4 IDEEA clusters.** CONTENT-TRACKING if AMI(cluster, source) ≥ .3 or AMI(cluster, qid) ≥ .3 on raw D+; after demeaning,
  DISCONNECTED if edge ratio < .5, CONNECTED if ≥ .8. Prediction (ours, not the proposal's): raw IDEEA clusters track question
  content for ≥ 4/6 traits, and demeaned D+ is CONNECTED for ≥ 4/6.
- Secondary: direction field (FIELD VARIES if field_coh < line-null 5th pct AND field_rot > line-null 95th pct), geo_ratio vs line
  null, profile over layers, acts_sys.

## 6. Steering (H5)
### 6.1 Layer (TRAIN, `steer.py sweep`)
Persona vector u_t = mean(D+_t) − mean(D−_t) (demeaned) at l ∈ {6, 9, 12, 15, 18}, multipliers {1, 2, 4, 8}, 10 own-source TRAIN
questions × 2 samples. l*_t = layer with the highest mean target P_t among multipliers whose coherence ≥ neutral − 1 (ties → lower l).

### 6.2 Arms at l*_t, all applied in the neutral context (one factor between neighbours)
| arm | definition | differs from the arm above by |
|---|---|---|
| prompt | graded prompt levels 0, +1, +2 (from the main generation, same questions) | — (trivial control) |
| pv | δ = α·u_t, full-d, all positions | prompting → activation addition |
| chord | δ(s) = λ·s·Wᵀ(π(1) − π(s_neu)), PCA-64, all positions | direction (path endpoints vs D± means) and PCA-64 projection |
| geo | δ(s) = λ·Wᵀ(π(s_neu + s(1 − s_neu)) − π(s_neu)) | **only the route** (same endpoints, same λ; δ identical at s = 1) |
| ideea | IDEEA-CAA nearest_pos_neg, KMeans(4) on raw D±, α·(nearest pos − nearest neg centroid) at the last position of every forward call | state-dependent direction (vs pv) |
π: kNN (k = 10) graph over the trait's TRAIN ladder rows in demeaned PCA-64, rows denoised by local means (20-NN, twice), edge weight
= distance² (density-favouring approximation of the density metric, Wurgaft et al. 2026), Dijkstra from the row nearest the
level −2 D− centroid to the row nearest the +2 D+ centroid, centroids appended, least-squares cubic in arc length (spline without
interior knots), 201 points uniform in arc length. s_neu = path point nearest the neutral centroid. These choices are fixed now.
Synthetic check (test_geom.py, design-sized, class SNR ≈ .13): fitted-path straightness .90 on a planted straight ladder (the
noise floor; a GCV spline gave .77, raw graph nodes .60) and .82 on a planted 90° arc (true .90). Path curvature therefore has a
noise floor, which is why the attribution rule in §6.4 compares against the same fit on line-null data.

### 6.3 Strengths
- Calibration (TRAIN, 10 own questions × 2): for pv, chord(s = 1) and ideea, strengths {.5, 1, 1.5, 2, 3, 4, 6, 8, 12}; the arm's max
  strength = smallest strength whose mean P_t reaches the prompt +2 mean on the same questions with coherence ≥ neutral − 1 (else the
  largest coherent one). geo uses chord's λ.
- Evaluation (TEST): Q_STEER = 20 own-source + 10 other-source TEST questions per trait; 8 strengths (fractions 0, 1/7, …, 1 of the
  max); S_STEER = **TBD-PC** samples (default 4). Every answer: 6 judge scores, coherence, per-token KL(steered ‖ unsteered).

### 6.4 Comparison at matched target gain (`analyze_steer.py`)
- G_common = min(prompt +2 gain, every arm's max coherent gain). Matched gains G_j = j/4 · G_common, j = 1, 2, 3; **G_2 primary**.
- At G_j, by linear interpolation at the first crossing (only coherent strengths): leakage_mean = mean over the other 5 traits of
  P_u(s) − P_u(0); leakage_nbr = same over the trait's neighbours; leakage_max; coherence; KL.
- Max jump J = max over consecutive strengths |ΔT| / |T(max) − T(0)|.
- Bootstrap over TEST questions (500), paired across arms.
- **H5a (proposal)**: geo leakage_mean < chord at G_2: GEO BETTER if the CI of (geo − chord) is < 0, WORSE if > 0, EQUIVALENT if inside
  ±.03, else no difference. Holm over traits. Same for geo vs pv and geo vs ideea (secondary).
- **H5b**: J_geo < J_chord (CI < 0).
- **H5-T (trivial control)**: if prompt leakage_mean ≤ every steering arm's (CI of arm − prompt > 0 for all arms) at G_2, the result is
  "prompting dominates" for that trait, stated in the abstract-level summary.
- **Attribution rule (CLAUDE.md rule 8)**: a geo-vs-chord difference is attributed to manifold curvature only for traits that are
  CURVED in H1 and whose fitted path straightness is below the 5th percentile of the same path construction on line-null data.
  Otherwise it is reported as an estimator effect of the path fit.
- Secondary: the same comparisons at matched per-token KL (rule 4); G_1, G_3.

### 6.5 Blind check of H5
Blind Claude labels (same protocol as K0) on N_BLIND_STEER = **TBD-PC** (default 240) steering answers: for each trait, arms pv, chord,
geo, ideea, at the eval strength nearest G_2, + prompt +1/+2. A H5a verdict is reported as confirmed only if the Claude-label
leakage difference has the same sign.

## 8. Pivot rules (rule 12)
- If H0 fails for ≥ 4 traits, the study stops after the prompt-profile report (the model cannot express the traits).
- If K0 fails for ≥ 3 traits, judge-based H1–H5 are not interpreted; next step is a judge fix, not more geometry.
- If H1 is UNDETERMINED for all traits, we report "underpowered" and do not add new statistics on the same data.
- If H5-T "prompting dominates" for all traits, the steering comparison is reported as secondary to that fact.
