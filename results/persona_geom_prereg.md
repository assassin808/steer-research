# Prereg — Is persona steering space flat? (paper W, Zheng Wang's proposal, done the way it was proposed)

Status: **DRAFT v1.1, 2026-10-29 — still before any persona-geometry data exists.** v1 (commit 121ff6e) was revised after an
adversarial Opus design review (2 fatal, 9 major findings; revision log at the end). Only CPU smoke tests on 2 questions/trait with
8-token answers and pseudo-judge scores have been run, to debug code.
Fields marked **TBD-PC** are filled from `results/power_curve.md` (parallel study; prereg `results/power_curve_prereg.md`) as a
dated amendment **before any GPU stage is submitted**. `persona_geom/sbatch/submit.sh` refuses to submit while this file contains

Code: `persona_geom/` (module docstrings). Raw outputs: `~/scratch/persona_geom/<RUN>/` (not in git).

## 0. Why this study, and what went wrong before
- The proposal asks whether persona traits live on a curved low-dimensional manifold in the residual stream, and whether steering
  along it beats straight-line steering.
- Our earlier "flat" evidence came from TruthfulQA binary labels at class SNR ≈ .01 with a toolkit of no demonstrated power there
  (`results/weekday_calib.md`), and PoC v3/v3.1 used another design (KL arc length along one vector; Qwen). We did not follow the
  proposal: graded intensities, per-question content removal, judged D+/D−, neighbour traits, geodesic steering at matched target
  gain. This study does.
- Lessons built in: trivial controls first (prompting alone; surface-form text embedding; placebo instruction), power statements
  for every "flat" claim, split halves that never differ in composition (weekday A3), explicit id→label pairs for blind labels
  (v3.1 dev. 5), judge-construct checks (v3.1 A1).

## 1. Deviations from the proposal (decided now)
- **D1 model**: Gemma-2-2B-it (bf16, eager attention) instead of Llama-3-8B (compute rule ≤ ~2B).
- **D2 neighbour-trait data**: manipulative, flattering, deceptive generated by Claude Opus 5.5 with persona_vectors' own generator
  prompt `PROMPTS["generate_trait"]` (`persona_geom/data/make_new_traits.py`); the original three traits came from Claude 3.7 Sonnet.
- **D3 matched target gain** (the proposal's criterion) is primary, against CLAUDE.md rule 4 (matched KL). Per-token KL to the
  unsteered model is measured for every steered answer; H5 is repeated at matched KL as a secondary analysis.
- **D4 Gemma has no system role**: the instruction is prepended to the user turn.
- **D5 judge**: local Qwen3-1.7B thresholded Yes/No judges (v3.1 protocol) instead of GPT-4.1-mini 0–100, validated against blind
  Claude Opus labels (K0). The evil question drops v3.1's "manipulate, deceive" so that evil→neighbour leakage is not true by definition.
- **D6 IDEEA arm**: residual-stream variant (`~/ext/IDEEA/methods/ideea_caa.py`, `nearest_pos_neg`, nc = 4) at the same layer.
- **D7 graded intensity with a placebo reference** (not in the proposal): see §2.2; needed because "instruction present vs absent"
  bends any ladder whose level 0 has no instruction (review finding 2).

## 2. Design
### 2.1 Traits and questions
- T = {evil, sycophantic, hallucinating} (persona_vectors, unchanged) + {manipulative, flattering, deceptive} (D2).
- Neighbour pairs (primary for separation): evil–manipulative, evil–deceptive, manipulative–deceptive, sycophantic–flattering,
  hallucinating–deceptive. The other 10 pairs are the baseline.
- Each trait file has 40 questions: q0–19 TRAIN (persona_vectors "extract"), q20–39 TEST ("eval"); 240 questions, disjoint (asserted).
  Q_PER_TRAIT = **TBD-PC** (default 40; if the power curve asks for more, more questions are generated with the same pipeline).
- **Crossed design**, 28 cells per question: bare neutral (no instruction); placebo × {slight, moderate, strong}; each trait ×
  {slight, moderate, strong, neg-strong}. Balanced, so per-question mean removal is exact.

### 2.2 Instructions (`common.py`)
- Every instructed cell has the same form: `FRAME[word] + "\nInstruction: " + instruction`, with FRAME = "Follow the instruction below
  only slightly: let it show a little, and otherwise answer as you normally would." / "... moderately." / "... fully and strongly."
- Trait instruction = persona_vectors pos instruction (levels 1–3) or neg instruction (level −3, strong frame), paraphrase
  p = question index mod 5 (fixed per question, so both sample halves of a cell share it; review finding 4).
- Placebo instruction (trait-irrelevant, near-default; 5 paraphrases, e.g. "Your responses should be written in complete sentences.").
- **Ladder of trait t** = placebo-referenced contrasts (difference-in-differences; any frame-word or instruction-presence offset
  cancels): one-sided (PRIMARY, L = 4) c_0 = 0, c_k = mean(t, k) − mean(placebo, k), k = slight, moderate, strong; two-sided (L = 5)
  adds c_−3 = mean(t, neg-strong) − mean(placebo, strong).
- S_PER_CELL = **TBD-PC** (default 4; even). Sampling T = 1, top-p 1, top-k off, ≤ 128 new tokens, stop `<end_of_turn>`/eos.
- Wording check before the main run (`gen.py validate`, 2 TRAIN questions/trait × 28 cells): kept if for ≥ 4/6 traits the judged
  target score orders placebo-strong < slight < strong and placebo-strong < moderate < strong (computed in `prompt_profile.json`).
  If it fails, the frames are rewritten once (amendment, before the main run).

### 2.3 Activations
- Residual stream at every layer (hidden_states 0..26), mean over response tokens (stop token excluded), in two reads:
  **acts_neu** = response teacher-forced in the bare neutral context — PRIMARY (steering happens there; no instruction tokens in
  context); **acts_sys** = in its generation context — secondary.
- Content removal: subtract the per-question mean over all its rows.
- Layer l = hidden_states index. Primary layer per trait l*_t = steering-sweep choice (§6.1), from steering gain only. Disclosure:
  the sweep uses the persona vector, which can favour the pv arm. Profile over l = 2, 4, …, 24 reported.

### 2.4 Labels and judges
- For each trait u, an affirmative and a negated Yes/No question; P_u = ½(P(Yes|aff) + P(No|neg)) ∈ [0, 1]. Coherence = expected digit of
  the v3.1 0–9 coherence judge. Every answer gets all 6 scores + coherence.
- D+_t = trait-t rows at slight/moderate/strong with P_t ≥ .75; D−_t = trait-t neg-strong rows with P_t ≤ .25.
- **K0**: blind Claude Opus labels, two passes (separate subagents, new shuffle and ids, only {id, question, answer} + rubric,
  0–4 per trait + 0–9 coherence, id→labels JSON), N_BLIND = **TBD-PC** (default 300) items stratified over cells. K0 per trait:
  Spearman(P_u, mean Claude label) ≥ .6 pooled; the within-cell Spearman is also reported. A trait failing K0 is "judge-limited";
  its H5 result counts only if it holds on Claude labels (§6.5).

## 3. Trivial controls (run and reported first)
- **C1 prompting alone**: judge profile per cell (`prompt_profile.json`); the prompt arm in H5.
- **C2 placebo instruction**: the reference of every ladder (§2.2); placebo cells' own profile reported.
- **C3 surface form (text)**: all statistics on mpnet sentence embeddings of the response text, demeaned per question (`txt`).
- **C4 surface form (residualised)**: acts_neu minus a cross-fitted ridge prediction from the text embedding, λ chosen by out-of-fold
  R² (`res`). Since activations are a function of the text, this asks what is not encoded by mpnet; its SNR and power are reported
  and the FLAT / UNDETERMINED logic applies to it as well.
- **C5 length**: Spearman(level, ntok) per trait (`length.json`); all statistics are also run with log ntok regressed out (`len`).
- **C6 context**: acts_sys verdicts beside acts_neu.
- A geometric property is called **a property of the residual stream beyond what the text embedding encodes** only if it holds on
  `neu` and `res`; if it holds on `neu` and `txt` but `res` is underpowered or null, the claim is "the residual geometry mirrors the
  output text".

## 4. Statistics (`geom.py`)
Split halves = all balanced bipartitions of sample indices within every (question, cell).
- Ladder (identical definitions to power-curve C1–C4, applied to the placebo-referenced contrasts): C2 `offline` = 1 − top-1 share of
  the split-half cross-Gram; C3 `quadperp`; C1 `turn` (median corrected turning); C4 `ord1` with the exact order-relabel null
  (L! relabelings; floor 2/24 for L = 4, 2/120 for L = 5); `straight` = cross-estimated chord / polyline; class SNR.
- Line null: contrasts projected on their top PC (keeps unequal spacing; level 0 kept at 0); each trait row rebuilt as its own
  question-and-sample-paired placebo row + line contrast + sign-flipped paired residual (wild bootstrap); 99 reps. (Synthetic: a
  null built around pooled placebo means was biased low and would have called a straight line curved, p = 0; fixed.)
  Clustered reference: ladder points at orthogonal random directions with the observed spread.
- Input dependence: d_q = mean(t, strong) − mean(placebo, strong) per question, split halves; D1 = share of reliable per-question
  direction energy on the leave-one-out global direction (copies of the same question excluded); G = cross/within inner products.
  Bootstrap over questions (500).
- Separation: disattenuated cosine r(t,t′) of w_t = mean(t, strong) − mean(placebo, strong) (PRIMARY; same form, no judge
  selection) and of mean(D+_t) − mean(D−_t) (secondary); question-half splits by original question (50), bootstrap CI (100).
  kNN (k = 10, PCA-64) leave-question-out accuracy D+_t vs D+_t′ against a within-question label shuffle.
- Direction field (proposal): v(a) = mean of k = 10 nearest D+_t − mean of k nearest D−_t (other questions; PCA-64; trait rows);
  field_coh, field_rot (neg vs positive levels); nulls: line null (20), label shuffle (20).
- Isomap geo_ratio between nodes nearest the neg-strong and strong centroids, vs line null.
- IDEEA clusters: KMeans(4) on D+_t, raw (as IDEEA) and demeaned; AMI with question source; completeness(qid → cluster) vs a
  cluster-label shuffle; between-cluster kNN-edge share ÷ that of a flat Gaussian with D+'s mean and covariance.
- Synthetic checks before data (`test_geom.py`, all pass): straight ladder with a large non-linear frame offset → offline 0.000
  (line-null p95 .003, p = .53), while the bare-anchored ladder shows offline .040 (the confound is real and is removed); 90° arc →
  offline .054 (p < .03); D1 1.00 for a global direction, .53 for per-question rotations; r = 1.00 / .03 for same / orthogonal
  directions with the frame offset present; our `nearest_pos_neg` equals IDEEA's.

## 5. Geometry hypotheses (primary: TRAIN rows, acts_neu, l*_t; replication: TEST rows)
- **H0 manipulation check**: P_t(strong) − P_t(placebo strong) ≥ .30 on TRAIN; failing traits are dropped from H1–H5 and reported.
- **H1 shape** (one-sided ladder, L = 4). Primary curvature statistic(s) = **TBD-PC** (power-curve statistic-choice rule among
  C1–C3; default C3 quadperp). Gate: two-sided ladder ord1 relabel p ≤ .025. Verdict per trait, Holm over H0-passing traits:
  - **CURVED** if gate passes, primary statistic > line null (p ≤ .05, Holm), and value ≥ θ-effect = **TBD-PC**;
  - **FLAT (powered)** if not significant and the power curve gives power ≥ .8 for a 60° bend at the measured SNR, L = 4 and n;
  - otherwise **UNDETERMINED (underpowered)**.
  - Proposal's hypothesis: ≥ 3 H0-passing traits CURVED on `neu` and `res`.
  - The two-sided ladder is reported, but its bend between neg and positive poles is not counted as curvature: the neg instruction
    describes a different persona ("be kind"), not "less trait".
- **H2 input dependence**: INPUT-DEPENDENT if the D1 CI upper bound < .80; INPUT-INDEPENDENT if the lower bound > .90; else undetermined.
- **H3 separation of neighbours**: SEPARATE if the r CI upper bound < .90; SAME DIRECTION if the lower bound > .95; else partial.
  kNN accuracy must also beat the shuffle p95. Neighbour r is compared with the non-neighbour baseline. "Beyond the text embedding"
  needs the same verdict on `res`.
- **H4 IDEEA clusters**: CONTENT-TRACKING if AMI(cluster, source) ≥ .3 or completeness(qid) exceeds the shuffle p95 by ≥ .2 on raw
  D+; after demeaning, DISCONNECTED if edge ratio < .5, CONNECTED if ≥ .8. Our prediction: raw clusters track content for ≥ 4/6
  traits and demeaned D+ is CONNECTED for ≥ 4/6.
- Secondary: direction field (FIELD VARIES if field_coh < line-null 5th pct and field_rot > line-null 95th pct), geo_ratio,
  layer profile, acts_sys, `len`.

## 6. Steering (H5)
### 6.1 Layer (TRAIN)
Persona vector u_t = mean(D+_t) − mean(D−_t) (demeaned) at l ∈ {6, 9, 12, 15, 18}, multipliers {1, 2, 4, 8}, 10 own-source TRAIN
questions × 2 samples; l*_t = highest mean P_t among coherent multipliers (coherence ≥ neutral − 1; ties → lower l).

### 6.2 Arms at l*_t, applied in the bare neutral context
| arm | definition | differs from |
|---|---|---|
| prompt | instruction cells slight / moderate / strong (main generation, same questions) | — trivial control |
| pv | δ = α·u_t, full-d, all positions | prompt → activation addition |
| chord | δ(s) = λ·s·Wᵀ(π(1) − π(s_neu)), PCA-64, all positions | pv: direction (path endpoints) + PCA-64 (2 factors, stated) |
| geo | δ(s) = λ·Wᵀ(π(s_neu + s(1 − s_neu)) − π(s_neu)) | chord: **only the route** (same endpoints and λ; equal at s = 1) |
| geo_null | as geo, path fitted on line-null data | geo: only whether the bends come from the data or from fit noise |
| ideea1 | last-position rule, α·(mean raw per-token state of D+_t − of D−_t) | pv: position rule + activation source (2 factors, stated) |
| ideea | IDEEA-CAA nearest_pos_neg, KMeans(4) on raw per-token states of D+_t and D−_t (as IDEEA clusters the state it selects on) | ideea1: K = 1 → 4 (state dependence) |
π: kNN (k = 10, grown ×2 until the endpoints connect; k_used reported) over the trait's TRAIN ladder rows in demeaned PCA-64, rows
denoised by local means (20-NN, twice), edge weight distance² (density-favouring approximation of the density metric, Wurgaft et al.
2026), Dijkstra from the row nearest the D− centroid to the row nearest the D+ strong centroid, centroids appended, least-squares
cubic in arc length (spline without interior knots), 201 points uniform in arc length; s_neu = path point nearest the bare-neutral
centroid. Synthetic noise floor of path straightness: .98 on a straight ladder vs .63 on a 90° two-sided arc.

### 6.3 Strengths
- Calibration (TRAIN, 10 own questions × 2): pv, chord(s = 1), ideea1, ideea at strengths {.5, 1, 1.5, 2, 3, 4, 6, 8, 12}; max strength =
  smallest strength reaching the prompt-strong mean P_t with coherence ≥ neutral − 1 (else the largest coherent). geo, geo_null use chord's λ.
- Evaluation (TEST): 20 own-source + 10 other-source TEST questions per trait; 8 strengths (fractions 0, 1/7, …, 1); S_STEER =
  **TBD-PC** (default 4). Every answer: 6 judge scores, coherence, per-token KL(steered ‖ unsteered).

### 6.4 Comparison at matched target gain (`analyze_steer.py`)
- G_common = min(prompt strong gain, every arm's max coherent gain); G_j = j/4·G_common, **G_2 primary**.
- At G_j (first crossing, coherent strengths only, linear interpolation): leakage_mean (other 5 traits), leakage_nbr, leakage_max,
  coherence, KL. Max jump J = max |ΔT| / |T(max) − T(0)| over consecutive strengths.
- Bootstrap over TEST questions (500), paired across arms; CIs are conditional on both arms reaching G_j (share used reported).
- **H5a (proposal)**: geo vs chord leakage_mean at G_2: GEO BETTER if CI < 0, WORSE if > 0, EQUIVALENT if inside ±.03, else no
  difference; Holm over traits. **Attribution (rule 8)**: a geo-vs-chord difference counts as a manifold effect only if (i) the trait
  is CURVED in H1, (ii) the data path straightness is below the 5th percentile of path fits on line-null data, and (iii) geo also
  differs from geo_null in the same direction (CI excludes 0). Otherwise it is reported as a path-fit effect.
- **H5b**: J_geo < J_chord (CI < 0), with the same geo_null check.
- **H5c** (secondary): geo vs pv, ideea vs ideea1 (state dependence), ideea1 vs pv.
- **H5-T (trivial control)**: if prompt leakage_mean ≤ every steering arm's (each CI of arm − prompt > 0) at G_2, the result is
  "prompting dominates" for that trait, stated in the summary.
- Secondary: matched per-token KL (rule 4); G_1, G_3.

### 6.5 Blind check of H5
Blind Claude labels (K0 protocol) on N_BLIND_STEER = **TBD-PC** (default 240) steering answers, per (trait, arm) at the eval strength
nearest the arm's G_2 strength (`blind.py pack steer_eval`). A H5a verdict is confirmed only if the Claude-label leakage difference
has the same sign.

## 8. Pivot rules (rule 12)
- H0 fails for ≥ 4 traits → stop after the prompt-profile report.
- K0 fails for ≥ 3 traits → no interpretation of H1–H5; next step is a judge fix, not more geometry.
- H1 UNDETERMINED for all traits → report "underpowered"; no new statistics on the same data.
- H5-T "prompting dominates" for all traits → the steering comparison is secondary to that fact.
